## Learning Hub lesson notebooks

These notebooks accompany [Learning Hub by DataPrepLab](https://www.datapreplab.com). They are independent learning material, not affiliated with or endorsed by Databricks.

- `notebooks/databricks/`: 13 SQL, Python and PySpark lesson labs. Import the raw notebook URL into Databricks Free Edition, attach serverless compute and follow the cells.
- `notebooks/colab/`: 5 compatible Python/PySpark labs for Google Colab. Spark examples install their dependencies in the learner's environment.

Read the setup and cleanup steps before running. Labs create example data and, where noted, tables or views; use a personal learning environment. No credentials or private client data are included. Free hosting/runtime limits and platform behavior may change.

The notebooks are generated from the lesson Hands-on lab sections. Each notebook links back to the full lesson for explanation, practice and further reading.
